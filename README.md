# projeto-efolio-ia

Projeto para resolver 10 instâncias de um puzzle de xadrez com procura A*.

## Executar

```bash
cd '/mnt/windows/Users/igorh/Documents/LEI/2 Semestre/Introdução a Inteligencia Artificial/projeto-efolio-ia'
python3 main.py
```

O ficheiro `resultados.csv` é gerado na raiz do projeto com o formato `ID;Tempo(ms);Solução`.
